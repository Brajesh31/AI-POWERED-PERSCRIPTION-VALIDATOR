# 📦 Installation

## Current status

There is no runnable application or implementation-specific dependency manifest in this repository. No supported runtime or dependency installation command can be provided yet.

## Future setup requirements

Once the application stack is selected, this guide must define:

1. Supported operating systems and exact runtime versions.
2. System packages and external services.
3. Dependency installation from committed manifests and lockfiles.
4. Environment variable names and safe example values.
5. Database provisioning and migrations, if required.
6. A local smoke test using synthetic data.
7. Expected output and troubleshooting steps.

Do not guess package commands or install arbitrary dependencies based solely on the project name. Never use production credentials or real patient records during local development.
