# ❓ Frequently Asked Questions

## Can I use this repository to validate a prescription today?

No. This repository currently contains documentation and project governance files only. There is no runnable application, AI model, OCR pipeline, API, or validation engine.

## Does the project replace a clinician or pharmacist?

No. The intended direction is professional review assistance. Any clinical decision must remain with a qualified professional.

## Will AI decide whether a medicine or dose is safe?

No. Generative AI must not be treated as clinical authority. Any future warning must be grounded in reviewed evidence and remain advisory.

## What does a successful software check mean?

Only that the defined technical check completed according to its documented rules. It does not establish that a prescription is clinically appropriate or safe.

## Can real prescriptions be used for testing?

Use synthetic data by default. Any use of de-identified health information needs documented approval and privacy review. Never publish patient data in GitHub issues or commits.

## Is the project production-ready?

No. There is no application implementation, test suite, security control implementation, clinical validation evidence or production deployment.

## Which technology stack does the project use?

No final technology stack has been selected. The README lists areas that need an explicit decision before implementation.
