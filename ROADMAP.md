# Roadmap

- Define supported prescription input formats and validation rules.
- Establish a privacy-preserving, consented, de-identified dataset strategy.
- Add deterministic parsing and clinical-rule validation before model assistance.
- Add confidence, explainability, audit history, and human approval workflows.
- Add automated tests for dangerous, ambiguous, incomplete, and malformed prescriptions.
- Document deployment, retention, access control, and compliance responsibilities.
