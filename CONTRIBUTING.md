# Contributing

Create a focused branch and explain the clinical, data, and engineering impact of each change. Do not commit patient data, prescription images, model credentials, or generated secrets.

Before submitting a pull request, run all available tests, linters, and validation commands. Changes involving model output must include edge cases, uncertainty handling, and a clear human-review path.

Pull requests should describe the change, validation performed, privacy implications, and any follow-up work.
